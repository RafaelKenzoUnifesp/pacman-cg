## 🎮 Sobre o Projeto

O projeto consiste no desenvolvimento de uma versão tridimensional do clássico jogo **Pac-Man**, utilizando **Three.js** e **WebGL**, permitindo a exploração do labirinto pela perspectiva em primeira pessoa (POV) do próprio personagem, além de contar com uma vista superior do cenário.

---

## 🚀 Como Executar

Basta abrir o arquivo `index.html` em qualquer navegador web moderno. É necessária conexão à internet para o carregamento da biblioteca Three.js via CDN.
